# 《Token燃烧模拟器》完整可玩版 2.0 设计

## 1. 产品定位

《Token燃烧模拟器》是一款面向休闲用户的十分钟轻策略 Roguelike。它借用现代 Coding Agent 的 IDE、聊天、终端和代码 Diff 语言，让玩家直观体验：模型能力不是无限的，每一次重新读取仓库、生成补丁和运行测试，都在消耗上下文、时间和真实可换算的 API 费用。

核心幻想不是“成为最会写代码的人”，而是“在 Agent 不完全可靠的情况下，做一个会控制证据、成本和风险的程序员”。

2.0 在 v1 骨架上补齐：流派构筑、中等内容包、一局复盘、引擎/样式模块化与发布抛光。

## 2. 设计支柱

### 看起来专业，操作起来轻松

界面呈现文件树、编辑器、Agent 对话、终端和 Token 明细，但玩家不需要真正编写代码。所有输入都是中等粒度操作卡，单次决策能立即理解。

### 模糊预测，准确结算

操作前只给出 Token 区间、费用区间、速度和风险等级。执行后显示准确的输入、缓存命中、输出 Token 与人民币费用。玩家面对的是受控不确定性，而不是精确算术题。

### 证据对抗自信

调查、代码和验证是三条不同进度。只做实现就交付虽然更快，但隐藏风险仍然存在；日志、测试和自审能够降低风险。模型越强，平均进度和可靠度越高，但高价模型仍可能失败。

### 失败要短，重开要有理由

每局约十分钟。失败后可沿同一随机种子完整重试一次，便于验证刚才的策略是否真的更好；之后必须生成新路线。局外只提供内容解锁，不永久堆高初始资源。

### 流派决定风格，复盘决定下一把

开局四选一工作方式，改变费用倍率、进度倍率、压缩保留与手牌权重。结算后复盘页把“哪次错序、哪次风险”变成可读证据。

## 3. 一局结构

路线共有七层：

1. 三选一开局项目。
2. 两条项目分支。
3. 项目或随机事件。
4. 中期项目。
5. 项目或上下文休整。
6. 最后一个常规项目。
7. 共同终点“周五 17:59 的发布”。

一条典型路线包含五个项目、一个随机事件、一个休整节点。更贪心的路径可能包含额外项目，奖励更多，但资源压力也更高。

## 4. 资源系统

| 资源 | 初始值 | 主要消耗 | 归零结果 |
| --- | ---: | --- | --- |
| API 预算 | ¥6,800（上限 ¥7,600） | 模型输入、缓存、输出 Token | 财务终止项目 |
| 上下文预算 | 220K | 读取文件、输出代码、测试结果 | Agent 遗忘任务 |
| Deadline | 58 格 | 每张操作卡、事件选择 | 客户取消项目 |
| 代码稳定度 | 78% | 高风险修改、失败交付、随机事件 | main 分支崩溃 |

项目成功返还 2 格 Deadline，形成小型节奏奖励。上下文不会在项目间自动清空，玩家必须使用压缩卡、缓存 Buff 或休整节点管理长期累积。

## 5. 流派（Archetype）

| id | 名称 | 被动 | 偏好卡 |
| --- | --- | --- | --- |
| frugal | 省钱流 | cost ×0.88，上下文 ×1.05 | 压缩 / 类型检查 / 精准补丁 |
| evidence | 证据流 | 连击纪律 +，调查/验证/自审 ×1.1 | 扫描 / 日志 / RFC / 测试 |
| rewrite | 重写流 | 实现 ×1.2，重写稳定伤害 ×0.75 | 重写 / 提取重构 / 热修 |
| compress | 压缩流 | 上下文 ×0.85，压缩少丢调查 | 压缩 / 结对调试 / 故障重放 |

流派起手会附带一个现有 Buff；`normalizeRun` 将旧档缺省回填为 `frugal`。

## 6. 项目遭遇与复盘

交付概率由进度完成度、模型可靠度、Buff、稳定度、隐藏风险与流程债务共同决定。界面不显示百分比，只显示“很稳、可交付、有风险、危险、像在许愿”。

2.0 新增 `RunState.audits: ProjectAudit[]`：交付/被打回时记录操作数、Token、费用、纪律变化与 topMistake。复盘页展示分数五段、纪律统计与项目时间线。

## 7. 操作卡与内容体量

- 18 张中等粒度操作卡（调查 / 实现 / 验证 / 控制）。
- 20 个项目（含 Boss）。
- 10 个随机事件、3 种休整、10 Buff、12 模型。

卡牌冷却与顺序罚则与 v1 相同；错序反馈在日志中显式拆解债务、稳定度与返工 Token。

## 8. 模型与费用

费用公式：

```text
费用 = 未缓存输入 × 输入费率 + 缓存 × 缓存费率 + 输出 × 输出费率
     × 流派费用倍率 × Buff 折扣
```

价格快照仍为 2026-09-10。所有品牌为戏仿名称。
